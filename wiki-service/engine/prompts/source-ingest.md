# Source Ingest Prompt

Use this when a user points to new private source material in a target vault.

Workflow:

1. Read `LLM Wiki/index.md` and `LLM Wiki/schema.md`.
2. Identify relevant existing pages.
3. Read the source from the private vault.
4. Extract entities, concepts, claims, decisions, contradictions, and open questions.
5. Create or update a source-summary draft.
6. Propose updates to concept/project/entity pages.
7. Append a log entry in the target vault.

Never commit source material to the engine repo.
